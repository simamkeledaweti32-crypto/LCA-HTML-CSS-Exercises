Learning HTML

HTML is the foundation of every website. It’s simple to start with because you can see your changes immediately in the browser. I like how you can structure content using headings, paragraphs and lists.

It’s a good first step before learning CSS and JavaScript.

Getting Started with CSS

CSS makes your website look better by controlling colors, fonts and layout. At first it was confusing but once I learned about selectors and properties it became easier.

I enjoy changing the background color and adjusting text size to make pages look clean.
